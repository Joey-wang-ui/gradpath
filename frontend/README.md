# Gradpath 页面原型

面向美研申请学生的响应式工作台，包含申请总览、探索项目、我的申请、文书工作区和个人背景。

`index.html` 和同内容的 `gradpath.html` 是自包含页面，已内嵌样式与脚本，可直接打开或作为单个 HTML 文件预览。不需要同时载入相邻文件，也不请求外部字体。

网页预览从仓库根目录启动配套服务：

```bash
python3.12 scripts/build_frontend.py
.venv/bin/python scripts/serve_gradpath.py --host 0.0.0.0 --port 3000
```

运行中的入口为 `/`，只返回约 4 KB 的 HTML，再分别加载具有正确 MIME 类型的 CSS 与 JavaScript；脚本预压缩，页面和资源禁止旧缓存。不要用聊天中的源码文件查看器代替网页预览。仓库根 `index.html` 也可作为普通静态服务器入口；`frontend/index.html` 和 `frontend/gradpath.html` 仍保留完整的独立页面。所有方式共用原来的浏览器数据键，不清空申请或文稿。

功能包括搜索与排名区间筛选、项目收藏、申请状态与对应工作区跳转、分校材料清单和项目笔记、待办勾选、文书本地自动保存和 TXT 导出。使用浏览器 localStorage，刷新后保留数据；清除站点数据会重置演示空间。右上角提供“联系作者”（邮箱与 GitHub）和账号占位窗口；登录与云端同步尚未接入。

导航按「探索」和「申请工作台」分组，区分跨校专业搜索与院校资料库。首页保留申请入口、进度卡片、申请助手和日期提醒，不再陈列 Top 10 或待办列表；待办仍在「我的申请」中管理。资料库按用户提供的 2027 排名 PDF 收录 51 所院校（含第 49 名的 3 所并列），完整保留原名次与并列规则。默认目录显示这 51 所，另保留 2 所旧基础档案，供已有收藏继续使用。

来源显示为“用户提供 PDF · 未独立核验官网”。该文件注明为整理版，并非 U.S. News 官方出版物。原始 PDF 随独立 HTML 一起内嵌，可从来源面板下载；SHA-256、页码和原表顺序均已保留。学校基础字段仍来自 IPEDS HD2023。详情见 [数据说明](data/README.md)。

此前的 6 个项目和截止日期保留为明确标注的演示内容；其余学校不提供未核验的项目日期。文书助手已实现服务端 GPT 接口和浏览器对话，需要配置服务端密钥才会调用 OpenAI；未接通时会明确提示，并可选用本地规则提示。不访问真实数据库。

页面使用系统字体，不依赖外部资源。`styles.css`、`assistant.js`、`map.js`、`app.js`、`documents.js`、`applications.js`、`shortlist.js`、`seasons.js`、`programs.js`、`program-search.js`、`motion.js` 和 `data/*.json` 是可编辑源文件。构建会校验排名年份、来源和完整性，再将数据及脚本内嵌。修改后运行以下命令更新独立页面，再重新打开预览：

```bash
python3.12 scripts/build_frontend.py
```

视觉样式参考作者作品集中的网格纸、轨道线与漂浮标签，采用蓝白渐变主调，配合白色卡片、浅蓝边框和蓝色重点区域。`motion.js` 提供卡片滚动入场和精细指针下的轻微倾斜；触屏不启用指针动效。动效默认开启，系统开启“减少动态效果”时自动使用静态显示；页面不再显示动效开关，也不再读取旧的 `gradpath-motion` 偏好。

## 浏览器检查

在仓库根目录执行：

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
# 已有系统 Chromium 时可直接测试；其他环境需先执行：
# .venv/bin/python -m playwright install chromium
.venv/bin/python -m pytest -q tests/test_school_catalog.py tests/test_program_catalog.py tests/test_frontend.py
```

检查项目筛选与收藏、申请状态持久化、文书保存与导出、任务进度、个人资料转义、助手演示标识，以及五个页面的手机布局。额外在禁止外部请求和浏览器存储的沙盒内验证单文件预览及导航。测试自动使用随机本地端口和独立浏览器数据，无需手动启动服务器。

全部 53 所院校档案（PDF 榜单 51 所及保留的 2 所旧档案）已使用内嵌的真实校徽图片，原始文件、校验值和来源说明见 [校徽素材说明](assets/crests/ATTRIBUTION.md)。申请状态可以进入该校材料清单、专属文书或结果记录；每所学校的材料进度与文稿分别保存。

保存背景档案后，页面展开选校建议，按目标方向的人工探索清单优先展示，再按排名区间和学校性质筛选；支持加入申请与对比。GPA、语言、预算会显示核验提醒，尚未用于项目适配或录取预测。正式定校仍需逐项目核对先修课、学位、费用和申请要求。

左上角可切换申请季（手机右上角的年份入口）：2026 Fall 及以前提供个人复盘，2027 Fall 继续现有申请，2028 Fall 及以后可以提前准备，支持输入 2000–2100 的其他年份。清单、状态、待办、项目材料、文书、版本和总结按申请季分别保存；个人背景与探索筛选偏好共用。切换年份不会改变资料库所收录的 2027 排名版本。旧浏览器数据按 2027 Fall 保留，无需手动迁移。


## 学院和硕士项目

左侧独立的「专业搜索」入口可跨学校搜索现有目录，支持中英文专业名、方向、学校关键词及多词组合，并按学校、学位和 10 组专业分类筛选。分类聚合已有目录的 `field`，不改动原始专业名称、ID 或来源；名称未能细分的条目仍归为「其他学科」。结果按学校、专业和操作分列展示，英文名称与标题相同时不重复显示；无结果的分类会禁用。每次展示 24 条，支持继续加载、查看原有详情及加入当前申请季。搜索结果会区分有官网目录依据与仍待核对的参考条目；这不是完整专业清单或招生资格核验。

点击任意学校的“了解项目”，可按学院或学术单位筛选，并搜索专业、中文/英文项目名称及学位。项目详情提供学院或项目的官方参考入口。当前 `data/programs.json` 覆盖 53 份院校档案，收录 2,090 个硕士项目与方向，其中 1,957 条附有官方目录快照，涉及 20 所院校。目录仍在补全，不宣称全校覆盖；名称目录依据与当季招生要求分别标注。每校另有“全校研究生入口”供查询其余项目。学费、截止日期、语言分数线等未经核验的信息不写入这些项目。

Caltech 的部分硕士学位可能随博士培养授予；这类条目标记为“先核对招生路径”，不提供普通独立硕士的一键加入按钮。学位目录与 U.S. News 排名来源分别保存。

同校的不同项目拥有独立申请 ID，例如 NYU 柯朗和坦登的计算机硕士。选中项目后，可以分别记录状态、材料、笔记、结果和文书；这些记录随申请季分别保存。已经编辑过的旧校级申请与旧草稿继续保留，新增项目不会覆盖它们。移出某个项目时保留其已有记录，并提供撤销。单纯收藏学校还未选择具体项目时，仍保留原有的校级待选项。

构建通过 `scripts/program_catalog.py` 检查院校覆盖、学院/项目关联、唯一 ID、官方域名及参考状态。这是数据结构与来源边界检查，不代表网络已验证项目开放招生或官方链接当前可达。


## GPT 文书助手与地图

点击导航栏的「院校资料库」整行只展开或收起分支，点击子项才切换页面。分支包含「院校主页」和「地图查看」两个子页面；手机上从底部导航向上展开，选择后自动收起。地图支持城市/学校搜索、区域与排名筛选、已关注院校、聚合标记、平移缩放，并可打开学院与项目。默认显示 PDF 榜单的 51 所，另可切换为全部 53 份档案。坐标与地理来源见 [数据说明](data/README.md)。

大量项目按 24 条分批加载，支持学院、项目文本、学位与授课形式筛选。每项保留所属目录及来源标记；校内衔接、联合学位或需博士路径的条目先核对申请方式。

文书工具栏的「与 GPT 打磨」打开持续对话，可逐次勾选背景、当前文稿、项目/待办作为上下文。模型回复显示为建议，不自动覆盖草稿。默认不发送文稿；草稿和版本仍保存在本浏览器。调用和对话错误会如实展示，不伪装为已连接的回复。

静态 HTML 只能预览界面。启用 GPT 时，在服务端配置 `GRADPATH_OPENAI_API_KEY`，再从仓库根目录启动配套服务：

```bash
.venv/bin/python scripts/serve_gradpath.py --host 0.0.0.0 --port 3000
```

服务同时提供前端和同源 API。可选模型变量 `GRADPATH_OPENAI_MODEL` 默认 `gpt-4.1-mini`，要求 API 项目有相应模型权限与额度。不要把密钥写进 HTML、浏览器存储或版本库。详细边界和部署注意事项见 [服务说明](../backend/README.md)。

执行 `.venv/bin/python -m pytest -q tests`，包含官方 SDK 模拟调用、服务端请求边界、来源证据、地图、项目筛选、文书与既有申请流程；这些自动检查不使用真实密钥或付费 API。


## 从聊天文件查看器下载预览

如果聊天里的 HTML 文件窗口只显示源码，应先下载完整网页，再交给浏览器渲染。可生成单文件下载包：

```bash
python3.12 scripts/build_frontend.py
python3.12 scripts/package_preview.py
```

输出为 `downloads/Gradpath-Preview.zip`，仅包含自包含的 `Gradpath.html` 与打开说明，无服务器代码、环境文件或密钥。解压后用普通浏览器打开 HTML。包内内容已通过禁止网络的 HTML 沙盒交互检查；当前云浏览器的管理员策略禁止 `file://` 导航，因此不把本机双击文件的检查描述为已通过。聊天附件查看器的渲染状态无法由网页服务器重启来修复。
